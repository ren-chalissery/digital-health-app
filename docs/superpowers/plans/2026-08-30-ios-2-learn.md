# iOS Plan 2 — Learn — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A clinician sees what is assigned to them, works through a module's sections and video, sits the quiz, and the app agrees with the web about their progress.

**Architecture:** One new package, `SimplicityLearn`, over a `LearningService` added to `SimplicityServices`. Markdown becomes native SwiftUI views rather than HTML. Progress is always the server's answer, never computed locally.

**Tech Stack:** As Plan 1 — Swift 6.2 tools / language mode 5, iOS 17+, SwiftUI with `@Observable`, Factory, Mockable, Swift Testing — plus AVKit for playback.

**Spec:** [docs/superpowers/specs/2026-08-29-phase5-ios-design.md](../specs/2026-08-29-phase5-ios-design.md)
**Follows:** [iOS Plan 1](2026-08-29-ios-1-foundation-and-sign-in.md)

## Global Constraints

Everything in Plan 1's Global Constraints still applies and is not repeated. In addition:

- `xcodebuild` needs `-skipPackagePluginValidation -skipMacroValidation`, and `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Suites that resolve from the Factory container extend `SimplicityTestCase` and are `@Suite(.serialized)`.
- `SimplicityLearn` depends on `Services`, `Design`, `Foundation`, `Api`. It must not depend on `SimplicityAuth`, and nothing may depend on it but the app target.
- Progress, status and completion are read from the server's response. The client never decides that a module is complete.
- Status wording is exactly the web's, from `web/src/app/features/learn/status-labels.ts`: `NOT_STARTED` "Not started", `IN_PROGRESS` "In progress", `COMPLETED` "Complete", `NEEDS_REDOING` "Updated since you finished".
- Every screen has an explicit failure state. A request that fails says so; it never shows an empty list as though the answer were "nothing".

## Two decisions this plan makes, and why

### Video ships without captions, and says so

Spec §6 assumed a WebVTT track could be side-loaded and offered through the system subtitle control. It cannot: the transcode emits a progressive MP4 through `FILE_GROUP_SETTINGS` (`MediaConvertTranscoder.outputGroup`), and AVFoundation only exposes subtitle renditions declared inside the asset. There is no manifest to declare one in.

The proper fix is an HLS output group with a caption rendition, which is a backend, infrastructure and web change — the web's `<video>` cannot read HLS outside Safari — and it needs its own spec. It is not attempted here.

So iOS plays the MP4 without captions. What it must not do is pretend they do not exist: `PlaybackResponse.captionUrl` tells us when a video *has* captions the app cannot show, and in that case the player says so and points at the web. A silently missing accessibility feature is worse than an acknowledged one.

`tinderbox2_ionic` is not a precedent here. It removed on-video captions altogether — `OverlayPlayerControlsPadView.swift` still carries the comment — and replaced them with a transcript panel fed by HLS manifest parsing, which a progressive MP4 cannot supply.

### Markdown becomes SwiftUI views, not HTML

The web renders to HTML and must escape every character of author input first, because a module author's markup would otherwise execute in a colleague's browser. On iOS there is no HTML and no script, so that entire class of risk is absent and the escaping would be pointless ceremony.

One part of it does port. `AttributedString(markdown:)` will happily parse `[tap me](javascript:…)` into a tappable link, and SwiftUI will open it. The link-scheme allowlist in `safeHref` is therefore the piece worth keeping, and the parser must not accept images either — the web's grammar has no image syntax and neither should ours.

`MarkdownBlock.swift`:

```swift
import Foundation

/// The subset of Markdown module sections are written in — the same grammar the web's renderer
/// accepts, expressed as values rather than as HTML.
public enum MarkdownBlock: Equatable {
    case heading(level: Int, text: AttributedString)
    case paragraph(AttributedString)
    case bullets([AttributedString])
    case numbered([AttributedString])
    case code(String)
}
```

`MarkdownParser.swift`:

```swift
import Foundation

public enum MarkdownParser {

    private enum Constants {
        static let fence = "```"
        /// Anything else — tel:, javascript:, a custom scheme — renders as plain text.
        static let allowedSchemes: Set<String> = ["http", "https", "mailto"]
    }

    /// Block structure is parsed line by line here, mirroring the web renderer's grammar, and only
    /// the inline formatting inside a line is handed to Foundation.
    public static func parse(_ source: String) -> [MarkdownBlock] {
        var blocks: [MarkdownBlock] = []
        var paragraph: [String] = []
        var bullets: [AttributedString] = []
        var numbered: [AttributedString] = []
        var code: [String] = []
        var inCode = false

        func closeParagraph() {
            guard !paragraph.isEmpty else { return }
            blocks.append(.paragraph(inline(paragraph.joined(separator: " "))))
            paragraph = []
        }
        func closeLists() {
            if !bullets.isEmpty {
                blocks.append(.bullets(bullets))
                bullets = []
            }
            if !numbered.isEmpty {
                blocks.append(.numbered(numbered))
                numbered = []
            }
        }
        func closeAll() {
            closeParagraph()
            closeLists()
        }

        for line in source.replacingOccurrences(of: "\r\n", with: "\n").split(
            separator: "\n", omittingEmptySubsequences: false
        ).map(String.init) {
            if line.trimmingCharacters(in: .whitespaces).hasPrefix(Constants.fence) {
                if inCode {
                    blocks.append(.code(code.joined(separator: "\n")))
                    code = []
                } else {
                    closeAll()
                }
                inCode.toggle()
                continue
            }
            if inCode {
                code.append(line)
                continue
            }

            if let heading = heading(in: line) {
                closeAll()
                blocks.append(heading)
                continue
            }

            if let item = listItem(in: line, marker: .bullet) {
                closeParagraph()
                if !numbered.isEmpty {
                    blocks.append(.numbered(numbered))
                    numbered = []
                }
                bullets.append(inline(item))
                continue
            }
            if let item = listItem(in: line, marker: .numbered) {
                closeParagraph()
                if !bullets.isEmpty {
                    blocks.append(.bullets(bullets))
                    bullets = []
                }
                numbered.append(inline(item))
                continue
            }

            if line.trimmingCharacters(in: .whitespaces).isEmpty {
                closeAll()
                continue
            }
            paragraph.append(line.trimmingCharacters(in: .whitespaces))
        }

        // An unterminated fence still emits what it captured; losing an author's content because
        // they forgot to close it would be worse than rendering it as code.
        if inCode, !code.isEmpty {
            blocks.append(.code(code.joined(separator: "\n")))
        }
        closeAll()
        return blocks
    }

    // MARK: Private

    private enum Marker {
        case bullet
        case numbered
    }

    /// `#` is level two: level one belongs to the page, not to a section's content. Same rule as
    /// the web renderer.
    private static func heading(in line: String) -> MarkdownBlock? {
        let trimmed = line.trimmingCharacters(in: .whitespaces)
        var hashes = 0
        for character in trimmed {
            if character == "#" { hashes += 1 } else { break }
        }
        guard (1...3).contains(hashes) else { return nil }
        let rest = trimmed.dropFirst(hashes)
        guard rest.first == " " else { return nil }
        return .heading(
            level: hashes + 1,
            text: inline(rest.trimmingCharacters(in: .whitespaces))
        )
    }

    private static func listItem(in line: String, marker: Marker) -> String? {
        let trimmed = line.trimmingCharacters(in: .whitespaces)
        switch marker {
        case .bullet:
            guard trimmed.hasPrefix("- ") || trimmed.hasPrefix("* ") else { return nil }
            return String(trimmed.dropFirst(2))
        case .numbered:
            let digits = trimmed.prefix { $0.isNumber }
            guard !digits.isEmpty else { return nil }
            let rest = trimmed.dropFirst(digits.count)
            guard rest.first == "." || rest.first == ")" else { return nil }
            let body = rest.dropFirst()
            guard body.first == " " else { return nil }
            return String(body.dropFirst())
        }
    }

    /// Foundation handles emphasis, code spans and links; we then remove anything the web's
    /// grammar would not have produced.
    private static func inline(_ text: String) -> AttributedString {
        var options = AttributedString.MarkdownParsingOptions()
        options.interpretedSyntax = .inlineOnlyPreservingWhitespace
        guard var attributed = try? AttributedString(markdown: text, options: options) else {
            return AttributedString(text)
        }

        for run in attributed.runs {
            if let link = run.link, !Constants.allowedSchemes.contains(link.scheme?.lowercased() ?? "") {
                // Keep the words, drop the tap. Removing the text as well would hide from the
                // author that their link was rejected.
                attributed[run.range].link = nil
            }
            if run.imageURL != nil {
                attributed[run.range].imageURL = nil
            }
        }
        return attributed
    }
}
```

`MarkdownText.swift` renders `[MarkdownBlock]` in a `VStack(alignment: .leading, spacing: Spacing.x3)`:

```swift
import SwiftUI

public struct MarkdownText: View {

    // MARK: Properties

    private let blocks: [MarkdownBlock]

    // MARK: Init

    public init(_ source: String) {
        self.blocks = MarkdownParser.parse(source)
    }

    // MARK: SwiftUI

    public var body: some View {
        VStack(alignment: .leading, spacing: Spacing.x3) {
            ForEach(Array(blocks.enumerated()), id: \.offset) { _, block in
                view(for: block)
            }
        }
        .frame(maxWidth: .infinity, alignment: .leading)
    }

    @ViewBuilder
    private func view(for block: MarkdownBlock) -> some View {
        switch block {
        case let .heading(level, text):
            Text(text)
                .font(level <= 2 ? .brandTitle : .brandBody.weight(.semibold))
                // Read out as a heading rather than as another line of prose.
                .accessibilityAddTraits(.isHeader)
                .frame(maxWidth: .infinity, alignment: .leading)

        case let .paragraph(text):
            Text(text)
                .font(.brandBody)
                .frame(maxWidth: .infinity, alignment: .leading)

        case let .bullets(items):
            list(items) { _ in "•" }

        case let .numbered(items):
            list(items) { "\($0 + 1)." }

        case let .code(source):
            Text(verbatim: source)
                .font(.system(.callout, design: .monospaced))
                .padding(Spacing.x3)
                .frame(maxWidth: .infinity, alignment: .leading)
                .background(Color.brandSurface)
                .clipShape(RoundedRectangle(cornerRadius: Spacing.x2))
        }
    }

    private func list(
        _ items: [AttributedString],
        marker: @escaping (Int) -> String
    ) -> some View {
        VStack(alignment: .leading, spacing: Spacing.x2) {
            ForEach(Array(items.enumerated()), id: \.offset) { index, item in
                HStack(alignment: .firstTextBaseline, spacing: Spacing.x2) {
                    Text(verbatim: marker(index))
                        .font(.brandBody)
                        .foregroundStyle(Color.brandTextSecondary)
                    Text(item).font(.brandBody)
                }
                .frame(maxWidth: .infinity, alignment: .leading)
            }
        }
    }
}
```

## Self-review against the spec

| Spec section | Covered by |
| --- | --- |
| §6 markdown, sanitising rules ported | Task 1 — as a link-scheme allowlist, since there is no HTML on iOS |
| §6 AVPlayer against the presigned URL | Task 6 |
| §6 WebVTT side-loaded through the subtitle control | **Not possible with a progressive MP4.** Deliberately deferred; the player says captions exist and points at the web. HLS needs its own spec |
| §6 refetch on an expired URL | Task 6 loads on demand; a mid-session expiry retry is **not** covered and is noted below |
| §6 progress is the server's opinion | Global constraints; Tasks 2, 5, 7 |
| §6 section completion and quiz attempts | Tasks 5, 7 |
| §2.7 online only, honest failure | Every view model has an `errorMessage`; Tasks 3, 4, 5, 6, 7 each test the failure path |
| §8 snapshot tests | **Not covered.** Deferred again — see below |

Two gaps carried deliberately, neither hidden:

**A playback URL expiring mid-session.** The URL is fetched when the video is asked for and lasts fifteen minutes; a section watched longer than that will fail on seek. The fix is a retry that refetches on failure, which needs a player error path this plan does not build. Worth its own task in a later plan rather than a rushed version here.

**Snapshot tests.** Plan 1 deferred them for want of anything worth snapshotting; the module reader is now worth it. They are still not here, because a snapshot suite needs a decision about recording, storage and tolerance that deserves more than a step in a task about something else.
